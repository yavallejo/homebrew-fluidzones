# homebrew-fluidzones

Homebrew tap for [FluidZones](https://fluidzones.com) — a macOS workspace launcher.

## Install

```bash
brew install yavallejo/fluidzones/fluidzones
```

## Update

```bash
brew upgrade --cask fluidzones
```

Binaries are signed with a Developer ID certificate and notarized by Apple. Source lives in a
separate private repository; this tap only tracks the public release DMG published in
[`yavallejo/fluidzones-releases`](https://github.com/yavallejo/fluidzones-releases).
